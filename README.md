\# Customer CLV \& Churn Prediction



Predicts customer churn risk and 12-month CLV on the Olist Brazilian

E-Commerce dataset (100K+ orders), translating model output into a

segmented retention strategy with ROI estimates.



\## Dataset

Download from Kaggle: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

Place the CSVs in `data/raw/` (not included in this repo due to license terms).



\## Structure

\- `notebooks/` — cleaning → RFM/CLV → churn model → business translation

\- `dashboard/` — Tableau workbook

\- `outputs/` — business memo, charts
